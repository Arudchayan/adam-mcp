# 0.3.0 candidate — downloads and dependable discovery

Status: implemented locally, **unreleased**. Source/version metadata targets 0.3.0.
This working tree is not a reviewed release commit. No tag, npm publication or
Registry update is authorized by this record.

## Delivered scope

- CLI-only selected-file downloads with `--confirm` and an explicit existing
  directory outside Git; pinned authenticated streaming, 256 MiB/120-second
  transfer limits, SHA-256, safe filenames and collision preservation.
- Temporary-file cleanup for ordinary failures and cancellation; atomic exclusive
  final creation on filesystems supporting hard links. Empty/HTML responses fail
  closed. Local completion metadata contains no file bytes.
- One PDF parser with at most eight waiting jobs and 32 MiB of queued input,
  a 30-second queue deadline and retryable overload errors.
- Scope-keyed complete-walk caches and shared operations for search/news/calendar;
  bounded entries, enrollment validation, TTL and per-caller cancellation retained.
- Synthetic cold/scoped/large-tree and queue-pressure benchmark, ADRs 0027/0028,
  updated product guidance, consistent root/package/server/Registry versions.

Deferred: batches, inventory diffs, traversal continuation, OCR and new ADAM types.
MCP still exposes the same tools, no writes and no file bytes. The CLI writes a
selected local file; it does not write to ADAM or authorize text extraction.

## Performance evidence

`benchmark:discovery` compared the pre-change `a799028` browser provider against
the candidate with current supporting modules. Workloads use an in-memory session;
no live ADAM navigation is measured. Each run uses a fresh provider.

| Synthetic workload | Baseline | Candidate |
| --- | --- | --- |
| 20-folder cold global walk | 22 navigations, 22 progress deliveries | 22 navigations, 22 progress deliveries |
| 30 scoped calls, 10 concurrent search/news/calendar batches | 31 navigations, 660 progress deliveries | 22 navigations, 66 progress deliveries |
| 60-folder global walk | 48 navigations; `partial:true` | 48 navigations; `partial:true` |

The scoped workload took 16.744 ms versus 3.090 ms in one comparative run. These
small one-run timings depend on warmup/order and must not be presented as live
speedup guarantees. Work counts show avoided dashboard navigation and repeated
progress/traversal work. Queue-pressure verification admits one active plus eight
waiting synthetic jobs (32 MiB waiting input), refuses excess and recovers.
