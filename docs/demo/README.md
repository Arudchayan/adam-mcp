# Demo

Screen recording of the fixture MCP server in [MCP Inspector](https://modelcontextprotocol.io/docs/tools/inspector), plus the public ADAM login page and the GitHub repo. No live student data.

```bash
npm run demo          # http://127.0.0.1:4177/
npm run demo:record   # rebuilds docs/demo/adam-mcp-demo.mp4
```
