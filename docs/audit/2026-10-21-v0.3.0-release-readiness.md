Date: 21 October 2026. Status: release preparation; **not published**.

## Independent review

Codex Security diff scan `c32b5de5-ec82-48e9-9c95-a49af0833077` completed and sealed
successfully. The completed canonical manifest/findings/coverage were read back.
The review found zero reportable findings in the reviewed candidate. This is a
diff-scoped review, not a security certification or whole-repository audit.

`codex-security-snapshot/v1:sha256:460fa9021ce423dc47219bc2ec5e87888d850c7292b08c46a71471e855dd2f74`.

Two independent read-only reviewers inspected 21 changed source/config/test files:

- `download_review`: CLI approval, file resolution, pinned streaming, per-hop
  credential acquisition, filenames, exclusive temporary/final creation and cleanup.
- `discovery_queue_review`: bounded PDF demand, scope/enrollment isolation,
  subscriber cancellation, refresh-detached ownership, protocol surface and
  version/distribution consistency.

Both reported no security candidates or release-blocking correctness issues.
The parent reviewed release documentation and lockfile/version consistency.
Unrelated pre-existing `.omo/**` and `.ignore` files are excluded from this release.
The unchanged supplied repository threat model was retained. Hard-link filesystem
support and hostile local-directory replacement limitations remain documented.

An initial report submission included host-managed coverage fields which runtime
validation rejected. The corrected submission omitted those fields, was accepted
as complete, and finalized successfully. No review findings or receipts were lost.
The plugin's aggregate usage receipt reports 5,415,851 tokens, including 5,232,640
cached input tokens across four threads; this is owning-conversation rollup
telemetry, not a measurement of incremental review cost.

  and fresh packed-consumer installation/audit.
- Full development/production dependency audit reported zero vulnerabilities.

  session status correctly returned disconnected/login-required, with no body data.

  not reproduced here. No persistent client configuration was overwritten.

  Graphical elicitation/progress, natural expiry and user-click cancellation are
  not claimed as live verified; registered-handler/wire/session regressions cover
